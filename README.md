# Unhinged

Digital playtest harness for **Unhinged**, currently tracking **Alpha 0.03 “Mongo.”**

## Mongo baseline

- 40-card decks
- 7-card opening hand
- Opening-hand mulligan: choose any number of cards, up to all 7; draw that many replacements, then shuffle the replaced cards back into the deck
- 26 Units / 8 Actions / 6 Items
- Single unrestricted battlefield
- Multiple Units may block one attack
- Universal Overflow
- Persistent Unit damage
- Survivors-only retaliation
- Items normally attach to Units and leave play with them

## Five prototype identities

Aggro, Midrange, Control, Tempo, and Kamikaze.

The web build contains five preconstructed 40-card decks. Secondary-pool deckbuilding and the experimental swing-card layer are LAB features rather than locked Mongo rules.
