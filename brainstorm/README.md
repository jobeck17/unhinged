# Brainstorm

[Ideas to explore](ideas.md) contains unimplemented concepts. [Scrapped experiments](scrapped.md) records approaches we set aside and why. Neither document changes the [current rules](../production/rules/unhinged-rules.md) or [card pool](../production/cards/README.md).

When an idea becomes a rule or card, remove its active proposal here and record the implemented version in the relevant production source. If a rejected approach is reopened, give it a fresh, focused test before promoting it.
