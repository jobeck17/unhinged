# Scrapped and tabled experiments

These are earlier directions, not current rules or pending implementation work. The [production rulebook](../production/rules/unhinged-rules.md) is authoritative.

| Experiment | Why it was set aside | Revisit only if |
| --- | --- | --- |
| Mongo browser playtest and Alpha 0.03 pool | Used Command/Stamina, Deploy, and simplified effects that do not represent Donut. The HTML and old pool were removed from the working tree. | A specific old hypothesis merits a fresh test in the Donut harness. |
| Two universal resource pools | Current game uses Fuel. | A measured resource problem cannot be solved within Fuel. |
| Three lanes, frontline/backline, staged marching | Adds positioning and mandatory progression to the current combat core. | A focused spatial variant produces a better decision. |
| Simultaneous reveal as the default turn | Replaced by alternating one-action Turns and interactive Blocks. | A bounded card effect uses reveal to create a distinct choice. |
| Separate objective score or mandatory outposts | Leader Health is the current win condition. | A future mode needs another objective. |
| Functional map or road card backs | Opposing players' cards intermingle and become awkward to separate. Bluffing has a clearer reason for face-down play. | A physical prototype resolves ownership and cleanup. |
| Mandatory Strike / Assault / Intercept / Counter sequence | Current Attack, Block, retaliation, and Guard rules supersede it. | A new combat test shows a benefit. |
| Claim Initiative | Current first passer acts first next Round after two consecutive Passes. | Initiative creates a demonstrable decision missing from current play. |
| Separate Junk Pile | Current Salvage cards use the normal discard. | A later set benefits from a distinct zone. |

Earlier proposals can be inspected in git history when their exact text matters. Do not copy old mechanics or card wording into current production without a new test.
