# Unhinged Documentation

This directory holds design guidance, decisions, ideas, and historical source notes. It is organized by authority:

| Area | Use it for | Authority |
| --- | --- | --- |
| [`production/`](../production/README.md) | Current rules and material being prepared for a playable product | Highest for active production work |
| [`current-state-2026-09-23.md`](current-state-2026-09-23.md) | The latest dated design checkpoint and rationale | Current Donut card revision and supporting rules decisions |
| [`../production/cards/README.md`](../production/cards/README.md) | Current 180-card roster, Trait/keyword register, draft data, and audit | Authoritative for current deck-card text |
| [`leaders.md`](leaders.md) | Current committed six-Leader cast, Style mapping, and Leader-specific design direction | Current Leader authority; exact card stats/abilities remain open |
| [`card-design-principles-2026-09-22.md`](card-design-principles-2026-09-22.md) | Card layout, readability, accessibility, and metadata requirements | Current design guide |
| [`terminology.md`](terminology.md) | Preferred terms and retired-language guardrails | Applies to all new work |
| [`idea-bank.md`](idea-bank.md) | Speculative mechanics and future concepts | Not approved until promoted deliberately |
| [`history/`](history/README.md) | Superseded checkpoints, experiments, and rollback notes | Historical context only |
| [`card-pool/`](card-pool/README.md) | Alpha 0.03 JSON pool and LAB source records | Legacy test data; not current card text |

When documents disagree, use the production rulebook for active playtest rules, then the open-decisions file for unresolved choices, then the latest dated checkpoint for rationale. Historical and legacy files explain prior work but do not silently change current rules.
