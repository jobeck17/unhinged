# Unhinged Traits

> Human-readable reference generated from the current card pool and Leader roster. This file describes the Traits that are **actually present in the repo right now**. Trait meanings and tribal roles are still provisional unless otherwise noted.

## Trait Philosophy

Traits serve three jobs:

1. **Creature / object identity** — e.g. Human, Animal, Vehicle, Object.
2. **Character or role identity** — e.g. Coach, Hacker, Florida Man.
3. **Tribal bridges** — Traits deliberately shared across colors so two-color decks can build around common identities.

Color identity should still come first. A Trait is a bridge, not a replacement for a color's core mechanical identity.

## Current Distribution Notes

- **Human** is intentionally broad and appears across all six colors.
- **Authority, Team, Hustler, Scavenger, Daredevil, Menace, Performer, Sketchy, Saboteur, Party, Fanatic, Outlaw, Vermin, Florida Man, and Undead** currently do the meaningful tribal work.
- **Coach, Hacker, Object, and Vehicle** are currently sparse identity/type Traits rather than full tribes.
- Some Traits intentionally spill beyond their original two-color bridge. That is healthy when it supports cross-pollination without erasing color identity.
- **Undead** is currently printed only on Kamikaze Units, but Reckless's **Bath Salts** can grant Undead, creating an additional cross-color hook.
- Trait counts should be audited as the pool evolves so no intended tribal bridge becomes accidentally unsupported.
