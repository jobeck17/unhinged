# Donut prototypes

The [focused Florida Man / HOA President duel harness](donut-duel/README.md) is the current executable prototype. It reads the active card pool and has targeted tests, reproducible heuristic runs, and documented limitations. It is not a general 180-card engine or a validated balance model.

See the [duel packet](../production/playtests/florida-vs-hoa/README.md) for deck lists and results. New prototypes should use the [current rules](../production/rules/unhinged-rules.md) and source data.
