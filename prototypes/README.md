# Prototype Index

## Donut — Unhinged Core 0.1

**Donut** is the planned successor to Mongo and the next rules prototype. It will implement the current production rules using a small purpose-built test pool rather than inheriting the legacy Alpha 0.03 cards.

Status: **planned; not implemented yet.**

The prototype should answer focused rules questions before the 180-card pool is rewritten.

## Mongo — Alpha 0.03

[Mongo browser simulator](mongo-legacy.html) is an archived mechanics experiment. It retains older Command/Stamina, Deploy, and Exhaust language and simplified resolution. Run it to study the experiment, not to test the current [production rules](../production/rules/unhinged-rules.md). A new simulator should implement current rules deliberately rather than inherit this one's mechanics by accident.

## Donut duel — September 24

The [focused Python duel harness](donut-duel/README.md) now implements the Florida Man / HOA President test decks and current combat. It includes reproducible heuristic runs, targeted rule tests, and documented pilot limitations. It is not a general 180-card engine or a validated balance model. See the [decklists and test report](../production/playtests/florida-vs-hoa/README.md).
