# Unhinged — Master Color Palette v1.0

**Status: PROPOSED / TESTING — not approved or locked.** Creative design reference, not a game-rule change. Maintained in [Visual Identity](README.md).

## Direction

Create a production color library, as an animation studio would: a recognizable core brand palette, curated supporting colors, Style accents, and consistent color decisions for box art, card art, packaging, card frames, effects, and digital UI. **Modern indie animation meets vintage comic books**: warm paper, slightly imperfect ink, bold but not uniformly neon colors. Avoid generic glossy/mobile-game rendering. All 60 colors below are exact sRGB HEX values.

## Brand hierarchy

**Primary colors:** Ink `#25242A`, Paper `#F6E9CE`, Unhinged Red `#E7463B`.

**Supporting accents:** Acid Yellow `#F2CE46`, Pool Blue `#38B9C5`, Cartoon Orange `#F28B42`.

These neutrals and brand anchors unite the game even when individual cards have different Style colors. Don't use every color on every card.

These are **Style** colors, not mandatory entire-card background colors or new gameplay rules. Give Styles distinguishing non-color shapes and visual motifs as well for grayscale and accessibility. A Leader's personality may use custom character sheets within this system.

## Application guidelines

1. **Approved colors by default.** Artists select from this library, rather than creating new ad hoc colors.
2. **Consistent hand-drawn ink.** Base outlines on the Ink/Shadow Ink family, with deliberate imperfections rather than perfectly smooth vector contours.
3. **Limited local palette.** Most illustrations should use approximately 8–14 of the 60 colors, not all 60 at once.
4. **Exceptions are allowed by review.** A visual joke or character may need a special color. Track exceptions before expanding the master library.
5. **Readability wins.** Stats, game text, UI, print contrast, and focal hierarchy outweigh palette purity. Check appearance in grayscale and with color-vision differences.
6. **Consistent Style signifiers.** Style identifiers remain recognizable on Leaders, card frames, packaging, and digital UI.

## Production use

- **Logo / packaging / card backs:** anchor on Ink, Paper and Unhinged Red; yellow/blue/orange as controlled accents.
- **Cards:** use brand neutrals for common structure; Style color as a clear identifier; avoid broad saturated fields behind small rules text.
- **Character art:** prepare recurring character-specific model sheets with skin, costume, prop, highlights and shadows selected from the master library.
- **Box art:** character palettes can vary, but brand anchors and ink treatment should create an immediately recognizable franchise look.
- **Effects / UI:** Effects & Signals are reserved for gameplay cues, special effects and emphasis; ensure UI meanings remain consistent.
- **Print:** HEX is a digital master reference. Before print approval, proof on actual stock and derive controlled CMYK/spot equivalents with a print vendor; HEX is not a reliable fixed print recipe.

## Before locking

1. Apply the same colors to **Florida Man, Crazy Cat Lady, Mad Scientist, and HOA President** side by side, with different personalities and scenarios.
2. Mock up a Leader, Character, Action, Item, card back, and box front.
3. Test ink and color accessibility, text contrast, print output and visual unity across illustrators.
4. Revise the palette based on the proofs, then explicitly change status from PROPOSED to APPROVED.

## Future visual references

As work progresses, keep character color sheets, frame/style usage rules, packaging treatments, and print specifications in this directory. Git history preserves prior iterations. Avoid separate conflicting palette files.
