# Unhinged — Visual Identity & Art Direction

**Status: PROPOSED / TESTING — not locked.** This section holds visual production references; it does not change game rules or canonical cards. Before committing to a final art direction, test the proposed palette on Florida Man, Crazy Cat Lady, Mad Scientist, and HOA President together.

## Documents

- [Master Color Palette v1.0](COLOR_PALETTE.md) — 60 named color swatches and exact HEX values, Style assignments, illustration guidance, production rules, and next steps.

- [Procreate Starter Kit v1.0](Unhinged_Procreate_Starter_Kit.zip) — downloadable ZIP with the 60-color ASE palette, setup recommendations, CSV and SVG swatch sheet. Does not include a native Procreate brush preset; proposed/testing.

## Visual goals

- A shared visual language for card illustrations, card frames, box art, packaging, and digital UI.
- Modern indie animation meets vintage comics: bold but slightly dirty colors, warm paper, imperfect hand-drawn ink, exaggerated personalities.
- Recognizable Styles without relying only on color; visual hierarchy and readability take priority.
- Character-specific model/color sheets can be developed here later, without creating a competing source of truth for gameplay.

## Maintenance

Keep the palette and future visual guidance here; link approved changes from the root README. The palette is a creative proposal until deliberately approved. Keep future exports (PDF, swatch images, printable sheets) alongside the source document when available.
